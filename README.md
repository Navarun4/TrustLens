# TrustLens 🔎
### Think Before You Click.

TrustLens is a privacy-conscious scam-awareness web app that helps users identify suspicious patterns in messages, understand potential warning signs, and make safer decisions online.

## 💡 Inspiration

Online scams often rely on urgency, fear, fake rewards, and impersonation to pressure people into acting quickly. TrustLens was created to help users pause, question suspicious messages, and understand the risks before clicking links or sharing sensitive information.

## ✨ Features

- **Message Analysis:** Checks text for suspicious patterns using rule-based detection.
- **Explainable Warnings:** Highlights potential red flags and explains why they may be concerning.
- **Safety Guidance:** Provides practical next steps when a message appears suspicious.
- **Interactive Learning:** Designed to help users practice recognizing scam tactics.
- **Privacy-First Approach:** Built with offline-first functionality in mind, minimizing reliance on external services.

*Note: Interactive learning, URL inspection, and other planned features should be listed as available only after they have been implemented and tested.*

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Rule-based pattern detection

## 🚀 Getting Started

TrustLens is designed as a lightweight web application.

1. Download or clone this repository.
2. Open the project folder.
3. Open `TrustLens_prototype.html` in a modern web browser.

No package installation is required for the standalone HTML version.

## 🔍 How It Works

1. Enter or select a sample message.
2. Run the analysis.
3. Review the detected warning signs.
4. Read the explanations and recommended safety steps.
5. Use the guidance to make a more informed decision.

## 🔐 Privacy and Limitations

TrustLens is an educational awareness tool, not a certified fraud-detection system. Its rule-based checks can produce false positives or miss sophisticated scams. A low-risk result does not guarantee that a message is safe.

Avoid entering real passwords, OTPs, PINs, banking details, or other sensitive personal information.

## 🇮🇳 If You Suspect a Scam

- Do not click suspicious links or share verification codes.
- Contact the organization using contact details from its official website or app.
- If financial fraud has occurred in India, contact your bank immediately and report it through the appropriate official cybercrime channels, including **1930** or [cybercrime.gov.in](https://cybercrime.gov.in/).
